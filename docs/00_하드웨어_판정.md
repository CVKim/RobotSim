## GPU 2장 사용 원칙

- **2×10GB ≠ 20GB.** 3080엔 NVLink 없음. 대형 모델 불가 판정은 두 장이어도 동일
- **Windows엔 NCCL 없음** → DDP(accelerate 2-GPU)는 WSL2에서만
- 네이티브 Windows 정답:
  1. 병렬 실험 — `CUDA_VISIBLE_DEVICES=0/1`로 시드 2개·ablation 쌍 (처리량 2배)
  2. 데스크톱·Isaac 뷰포트를 GPU1 고정(`--/renderer/activeGpu=1`), GPU0 10GB 전부 헤드리스 학습
  3. HIL-SERL actor/learner 프로세스를 카드 1장씩

## 환경 배치 원칙

- 학습·시뮬: Windows / WSL2 자유
- Isaac Sim: **네이티브 Windows만** (WSL2 미지원)
- JAX 계열(MJX/Playground): WSL2만
- CUDA 확장 컴파일 필요한 인식 모델(FoundationPose, GraspNet 계열): WSL2 + Docker 기본
- USB 장치(게임패드·카메라·시리얼): **네이티브 Windows만** (WSL2 포워딩은 취약 경로)
