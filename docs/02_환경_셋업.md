# 환경 셋업 가이드 (Windows 11, RTX 3080 ×2)

> 전부 무료. 순서대로 하면 됨. ①만 있으면 T1/T2/T3/T6이 바로 돌아간다.

## ① 네이티브 Windows — LeRobot 학습 환경 (지금 바로)

확인된 로컬 환경: Anaconda Python 3.12.4 (`D:\anaconda`) — LeRobot 요구사항(Python ≥3.12) 충족.

```powershell
# 1. venv 생성 (E:\Robot_Sim\.venv)
D:\anaconda\python.exe -m venv E:\Robot_Sim\.venv
E:\Robot_Sim\.venv\Scripts\Activate.ps1

# 2. CUDA torch (Windows pip 기본은 CPU 휠이므로 반드시 cu124 인덱스 명시)
python -m pip install --upgrade pip
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124

# 3. LeRobot + 시뮬 환경
pip install "lerobot[pusht,aloha]"    # extras 이름이 바뀌었으면: pip install lerobot 후 gym-pusht, gym-aloha 개별 설치
pip install gym-hil                    # HIL-SERL 시뮬 (T3)

# 4. 검증
python -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.device_count())"
# 기대: 2.x.x+cu124 True 2
```

참고:
- TorchCodec은 Windows+PyTorch<2.8에서 미지원 → pyav 자동 폴백(성능만 약간 손해, 무시 가능)
- WandB 계정(무료)을 만들어 학습 곡선 기록 습관화 — 오프라인 모드(`WANDB_MODE=offline`)도 가능 (로컬 전용 유지 시)

## ② WSL2 Ubuntu 22.04 — JAX·CUDA 확장 컴파일용 (T1 일부, MJX)

```powershell
wsl --install -d Ubuntu-22.04
```

WSL2 안에서:
```bash
# CUDA는 Windows 드라이버가 자동 노출 (별도 드라이버 설치 금지, toolkit만)
pip install "jax[cuda12]"                 # MJX / MuJoCo Playground용
pip install mujoco mujoco-mjx playground  # T8 선택
# Grounded-SAM-2, FoundationPose(Docker), GraspNet 계열도 여기서
```

주의: **Isaac Sim은 WSL2 불가.** USB 장치도 WSL2로 쓰지 않는다.

## ③ Isaac Sim 4.5 + Isaac Lab — 네이티브 Windows (T4/T5/T6)

1. NVIDIA 계정(무료) → Omniverse Launcher 또는 직접 다운로드로 **Isaac Sim 4.5.0** 설치 (5.x 아님!)
2. Isaac Lab은 4.5 호환 버전(2.0/2.1)을 pip/소스로: Python 3.10 venv 별도 구성, Windows 긴 경로 지원 활성화, MSVC Build Tools 필요할 수 있음
3. 실행 원칙: 학습은 headless, 뷰포트 필요 시 GPU1 고정
   ```
   --/renderer/activeGpu=1  --/app/content/emptyStageOnStart=true
   ```
4. 첫 검증: Isaac Lab 예제 `Isaac-Lift-Cube-Franka-v0`을 headless + num_envs=512로 실행하며 nvidia-smi로 VRAM 관찰
