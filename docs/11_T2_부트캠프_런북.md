# T2 런북 — LeRobot 시뮬 모방학습 부트캠프

> 목표: 하드웨어 없이 "데이터셋 로드 → 학습 → 평가" 전체 루프 체득 + 첫 학습 곡선 확보.

## Step 2 — PushT + Diffusion Policy (첫 학습, 3080에서 수 시간)

```powershell
$env:WANDB_MODE = "offline"   # 로컬 전용 로깅
lerobot-train `
  --policy.type=diffusion `
  --dataset.repo_id=lerobot/pusht `
  --env.type=pusht `
  --batch_size=64 `
  --steps=25000 `
  --output_dir=E:\Robot_Sim\runs\pusht_diffusion `
  --policy.device=cuda
```

- OOM 시: `--batch_size=32` → 16 순으로. (공식 가이드: Diffusion 8–14GB@BS8 기준이지만 PushT는 96×96이라 가벼움)
- 두 번째 GPU에 동시 실험: 새 셸에서 `$env:CUDA_VISIBLE_DEVICES="1"` 후 다른 시드/파라미터로 실행

## Step 3 — 평가 롤아웃 (성공률 수치 만들기)

```powershell
lerobot-eval `
  --policy.path=E:\Robot_Sim\runs\pusht_diffusion\checkpoints\last\pretrained_model `
  --env.type=pusht `
  --eval.n_episodes=50 `
  --eval.batch_size=10
```

산출물: 성공률(%) + 평가 영상 mp4 → `runs/` 아래 저장. **50 에피소드 이상**으로 통계적 정직성 확보.

## Step 4 — gym-aloha + ACT (VRAM 여유 확인용)

```powershell
lerobot-train `
  --policy.type=act `
  --dataset.repo_id=lerobot/aloha_sim_transfer_cube_human `
  --env.type=aloha --env.task=AlohaTransferCube-v0 `
  --batch_size=8 --steps=50000 `
  --output_dir=E:\Robot_Sim\runs\aloha_act --policy.device=cuda
```

(aloha 환경 설치 필요 시: `pip install "lerobot[aloha]"` 또는 `pip install gym-aloha`)

## Step 5 — SmolVLA 파인튜닝 맛보기 (10GB 한계 실측)

```powershell
lerobot-train `
  --policy.path=lerobot/smolvla_base `
  --dataset.repo_id=lerobot/svla_so101_pickplace `
  --batch_size=2 `
  --steps=5000 `
  --policy.device=cuda `
  --output_dir=E:\Robot_Sim\runs\smolvla_test
```

- `freeze_vision_encoder`는 기본 true. OOM 시 batch 1 + `--policy.grad_clip_norm` 유지, gradient accumulation 옵션 확인
- **`nvidia-smi -l 2`로 피크 VRAM을 기록해둘 것** — "10GB에서 SmolVLA 파인튜닝 실측" 자체가 콘텐츠
