## Week 1 — T1 리포트 완성 + LeRobot 첫 학습

**목표**: "3D 비전" 증거물 1호 완성 + GPU 학습 파이프라인 가동

1. **빈피킹 인식 v2** (2~3 저녁)
   - 픽포인트 출력: 상면 중심 + 법선(주변 X/Y/D 평면 피팅) → 석션 그래스프 후보 JSON
   - 빈 슬롯 검출: 상면 층에서 '박스 없는 영역' → 다음 적재 위치 제안 (역방향 = 팔레타이징)
   - 층 상태 자동 판정: 층 깊이 → 층 번호, 잔여 박스 수 → 세션당 상태 리포트
2. **PushT + Diffusion Policy 학습** (걸어두기): 런북 Step 2 → 학습곡선 + 50롤아웃 평가 성공률
3. **gym-aloha ACT** (걸어두기): VRAM 여유 실측 기록
4. **T1 기술 리포트 v1** (`docs/20_빈피킹_인식_리포트.md`): 방법·수치·실패 사례·노이즈 모델 챕터 포함

**완료 기준**: 픽포인트 오버레이 이미지 + 성공률 수치 2개(PushT/ALOHA) + 리포트 초안
**커리어 매핑**: 씨메스·현대차 Perception AI ("3D 데이터 처리", "파지 자세 추정")

## Week 2 — 강화학습 주간 (T6 학습 + T3 HIL-SERL)

**목표**: "강화학습" 증거물 — 학습 곡선과 베이스라인 비교가 있는 진짜 RL 결과

1. **팔레타이징 PPO 학습**: `palletize_env` + action mask → PPO (sb3 또는 자체 구현, <4GB)
   - 실측 치수 분포(293×219×283, σ 반영)로 박스 생성
   - 평가: 부피 활용률 — **DBL 휴리스틱 vs PPO vs PPO+mask** 3자 비교 그래프
   - ablation: action mask 유무 / 지지율 임계 0.6 vs 0.8
2. **gym-hil HIL-SERL 완주** (주말 1회): 개입 포함 학습 → **개입률 감소 곡선** 확보
   - actor/learner를 GPU0/GPU1로 분리해 2-GPU 아키텍처 실증
3. 여유 시: FastTD3 또는 SAC로 PushT 재학습 → PPO 계열과 wall-clock 비교 한 줄

**완료 기준**: RL 학습곡선 2종 + 휴리스틱 대비 우위(또는 정직한 열세 분석) + 개입률 곡선
**커리어 매핑**: 라이온·LG "강화학습", 두산 "시뮬레이션 학습" — 면접에서 곡선 보여주며 설명 가능

## Week 3 — T5 디지털트윈 + 합성데이터 + sim2real (플래그십 착수)

**목표**: "모션 시뮬레이션 환경 구축 + 합성데이터 생성" 증거물

1. **BlenderProc2 합성 장면** (Windows 네이티브, 먼저):
   - 팔레트 + 293×219×283mm 박스 physics-drop, 톱다운 카메라를 실측 지오메트리(높이 ~4.2m, ToF FOV)와 매칭
   - **실측 노이즈 모델 주입**: σ(I) 파워로우를 depth에 적용 (기본 Kinect 노이즈 모델과 비교 ablation — "거리 기반 기본 모델은 이 센서에 틀리다"가 셀링 포인트)
   - RGB+depth+seg 3천 장 생성
2. **합성 전용 학습 → 실데이터 평가**: 박스 세그멘테이션 모델(YOLO11-seg급) 학습 → 실제 30세션에서 mAP → **sim2real 갭 정량화** (노이즈 모델 유/무/종류별)
3. **Isaac Sim 4.5 설치** + 같은 장면 Replicator 재현 착수 (이력서 키워드용 — BlenderProc 결과와 비교)

**완료 기준**: 합성 데이터셋 + "노이즈 모델별 sim2real 갭" 표 1장 (이게 포트폴리오의 심장)
**커리어 매핑**: 두산 "물리엔진 시뮬 환경&데이터 생성", 현대차 "합성 데이터 생성", 홀리데이 전체

## Week 4 — 종합·고도화·공개

**목표**: 산출물을 채용시장이 읽는 형태로 포장

1. **SmolVLA 파인튜닝 실측** (걸어두기): 공개 SO-101 데이터셋으로 10GB 한계 실측 (batch/VRAM 표)
   → "π0/GR00T는 왜 안 되는지 + SmolVLA는 어떻게 되는지" 실측 기반 서술 확보
2. **후크 6D 정합 실험**: 대차 후크를 템플릿 포인트클라우드로 ICP 정합 → 도킹 정렬 오차 리포트
3. **RGB-ToF 외참 정합** (빈피킹 데이터): 박스 코너 대응점으로 외참 추정 → RGB 세그멘테이션을 포인트클라우드에 투영하는 파이프라인 (Week 1 결과 업그레이드)
4. **종합 리포트 + 레포 정리**: README에 결과 이미지·표 배치(익명화 준수), 기술블로그 1편(노이즈 모델 스토리 추천 — 가장 독창적)
5. **다음 달 결정**: SO-ARM101 구매 여부 (게이트: 여기까지 완주했으면 사도 됨), Isaac Lab RL 심화 vs 듀얼부팅

**완료 기준**: 레포가 "채용담당자가 10분 봐도 이해되는" 상태 + 블로그 1편 초안
