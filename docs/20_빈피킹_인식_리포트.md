# 이적재 공정 ToF 인식 기술 리포트 (T1)

> 데이터: 산업 현장 고정 ToF 카메라 30세션 (X/Y/D/I 640×480 float32, mm) + RGB 5MP.
> 원본 비공개 — 본 리포트는 집계 수치와 depth 시각화만 포함 (승인 범위: `03_공개전략_및_데이터보안.md`).
> 코드: `tools/` · 수치 원본: `explore/` JSON.

## 1. 요약

라벨·학습 없이 ToF 4채널만으로 이적재 공정의 인식 문제(검출·치수·픽포인트·순서)를 풀고,
그 출력을 강화학습 정책과 합성데이터 생성의 입력으로 연결했다. 핵심 수치:

| 항목 | 결과 |
|---|---|
| 박스 검출 | 148개/30세션 (무학습 기하) |
| 상면 치수 | L 293.0±9.2 / W 218.8±9.9mm (CV 3%) |
| 박스 높이 | 283mm (층간 깊이차) |
| 픽포인트 | 기울기 평균 0.95° (max 2.7°), 평면 RMS 5.4mm |
| 픽 순서 규칙 | 열 스캔 규칙로 실제와 81% 일치 (그리디 50%) |
| 노이즈 모델 | σ(mm)=180.3×I^-0.805 (정적픽셀 12.7만) |
| 공정 복원 | 소스 감소 ↔ 목적지 스택 성장(770→1260mm) 동시 추적 |
| 후크 반복성 | 8.2mm RMS (실이동·검출바이어스 분리 후) |

## 2. 검출 파이프라인 (무학습)

1. **층 깊이**: 중앙 ROI 깊이 히스토그램 최대 피크 = 상면 층 (±40mm 마스크)
2. **박스 분리**: 순수 깊이 모폴로지는 이음새의 점선형 무효 픽셀 때문에 실패(파편화↔병합 딜레마).
   해법: **강도(I) 채널 Canny 에지로 절단** — D와 I는 동일 센서라 픽셀 정합이 완벽
3. **치수**: X/Y 좌표맵(mm)에서 minAreaRect → 픽셀이 아닌 실측 치수
4. **픽포인트**: 박스별 3D 포인트 SVD 평면 피팅 → 중심(석션점) + 법선(접근벡터) + 기울기
5. **슬롯 추적**: 만재 세션을 기준 레이아웃으로 중심 매칭 → 세션 차분 = 실제 픽 이벤트

검증: 평면 RMS 5.4mm가 노이즈 모델 예측(σ≈2~5mm@3m)과 정합 — 독립 분석 간 교차 검증.

## 3. 센서 노이즈 모델

30세션에서 정적 픽셀을 자동 선별(유효≥25세션, 중앙값±30mm 내 80%)해 시간적 산포를 측정:

- σ-거리: **비단조** (2.75m 부근 범프) — 거리 기반 표준 모델 부적합
- σ-강도: 로그-로그 선형 → **σ(mm) = 180.3 × I^(-0.805)** (샷노이즈 물리와 정합)
- 응용: 합성 depth 노이즈 주입을 σ(I)로 캘리브레이션 → sim2real 사다리의 0→0.43 구간을 만든 요인

## 4. 공정 복원 (이적재)

- 초기 가설(빈 슬롯 재적재)은 데이터 소유자 확인으로 교정 — 실제는 소스→왼쪽 목적지 스택 이적재
- 좌측 ROI 상면 깊이 추적: 픽킹 진행에 따라 770→1015→1180→1260mm 계단 상승, 반출 시 0 복귀
- 픽 순서 마이닝: 불일치 전수가 "같은 열에서 더 먼 것 우선" 패턴 → **열 스캔 규칙** (일치 81%)

## 5. 다운스트림 연결

- **팔레타이징 RL**: 실측 치수 분포로 환경 시드 → MaskablePPO 64.9박스/68.5% (휴리스틱 +14.7%)
- **통합 데모**: 실장면 상태 이식 → PICK(최소 동선)·PLACE(목적지 스택) 제안, 실제 순서로 검증
- **합성데이터**: 실측 지오메트리 역산 재현(상면 깊이 오차 9mm) → sim2real 사다리 0.00/0.43/0.99

## 6. 한계·다음 단계

- 치수 GT가 줄자 실측이 아닌 내부 일관성 기반 — 현장 접근 시 mm 오차 절대 평가 필요
- 2층 치수가 1층 대비 ~4% 작게 측정되는 거리 의존 바이어스 — 캘리브레이션 챕터 후보
- RGB(5MP)와 ToF 미정합 — 외참 추정 후 RGB 분할(SAM2)과 성능 비교 예정
- 픽 순서 잔여 3/16 불일치: 열 내부 순서 규칙 — 추가 데이터로 검증 필요
- 후크 검출 바이어스 세션(병합-분리 경로) — Intensity 병용 세그먼테이션으로 개선 여지
