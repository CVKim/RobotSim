## 환경 이슈 기록

- **torch 2.9~2.11 전 빌드가 Windows 26200에서 c10.dll WinError 1114** (CPU 빌드 포함, 페이지파일·AVX·런타임 전부 무관) → **2.8.0+cu126로 해결** (pytorch#166628 참고, 2.9+ 리그레션)
- lerobot 0.6.1: 학습엔 `lerobot[training]` extra 필수(accelerate), env는 `[pusht]` 등 별도
- torchcodec DLL 로드 실패는 pyav 폴백으로 무해 (Windows+torch<2.8 계열 알려진 제약)
- cv2.imread 한글 경로 실패 → `imread_kr()`(np.fromfile+imdecode)
- PS 콘솔 cp949: 파이썬 print에 ±·≈·한글 시 UnicodeEncodeError 주의
