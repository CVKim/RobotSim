> 목적: 이 프로젝트를 **경력기술서·포트폴리오·면접**에서 바로 꺼내 쓸 수 있는 형태로 정리.

## 0. 합성데이터/sim2real이 뭔지 — 한 문단 설명

**문제**: 검출 모델을 학습하려면 라벨링된 이미지 수천 장이 필요한데, 현장 데이터는 수집도 어렵고
라벨링 비용(장당 수백~수천 원 + 시간)이 크다. 현장이 바뀌면 또 처음부터.

**해법(합성데이터)**: 3D 시뮬레이터(물리엔진)에서 박스를 떨어뜨려 장면을 만들고 가상 카메라로 렌더링하면
**이미지와 정답 라벨(어느 픽셀이 몇 번 박스인지)이 공짜로, 무한정** 나온다. 문제는 시뮬 이미지와 실제
센서 이미지가 미묘하게 달라서(노이즈·재질·조명) 시뮬로 학습한 모델이 실데이터에서 성능이 떨어지는 것 —
이 차이가 **sim2real 갭**이고, 갭을 줄이는 기술(실측 노이즈 주입, 도메인 랜덤라이제이션)이 이 분야의 핵심 역량.

**이 프로젝트에서 한 것**: 실측 ToF에서 노이즈 법칙(σ=180.3×I^-0.805)을 직접 측정 → 그 법칙대로 합성
depth에 노이즈를 입혀 → "노이즈 넣은 합성으로 학습하면 실데이터 성능이 얼마나 오르는가"를 정량 측정.
JD의 *"물리엔진 기반 시뮬레이션을 활용한 강화학습 환경 구축"*, *"합성 데이터 생성"* 요구에 정확히 대응.

## 1. 경력기술서용 프로젝트 요약 (복붙 기반)

> **물류 이적재 공정 3D 인식·강화학습 파이프라인 구축** (개인 연구, 2026)
> 산업 현장 ToF 카메라 데이터(X/Y/D/I)만으로 무학습 기하 기반 박스 검출·mm 치수측정 파이프라인을
> 구축하고(148개 검출, 치수 변동계수 3%), 센서 노이즈 법칙을 실측(σ∝I^-0.8)해 물리 시뮬레이션 기반
> 합성 학습데이터에 반영. 실측 박스 치수로 시드한 팔레타이징 강화학습 환경을 직접 설계해 MaskablePPO로
> 휴리스틱 대비 적재 박스 수 +14.7%(활용률 68.5%)를 달성하고, 인식 결과를 정책 입력으로 잇는
> 무교시(teaching-less) 픽·플레이스 제안 시스템을 실제 작업 로그와 대조 검증(top-2 일치 81%).
> LeRobot 기반 VLA(SmolVLA-450M) 파인튜닝 파이프라인을 10GB GPU에서 실측 구축.

## 2. 항목별 상세 (STAR 서술 — 면접 답변 뼈대)

### ① ToF 3D 인식 파이프라인 (JD: "AI비전모델 개발·로봇 제어 연동", "Teaching 없는 교시")

- **상황**: 이적재 공정의 고정 ToF 카메라 데이터 30세션, 라벨 없음
- **과제**: 라벨·학습 없이 박스 위치·치수·픽 위치를 뽑을 수 있는가
- **행동**: 깊이 히스토그램으로 적재 층 검출 → **깊이와 픽셀 정합이 완벽한 강도(I) 채널의 에지로 박스
  이음새를 절단**(순수 깊이 모폴로지는 실패 — 시행착오를 문서화) → X/Y 좌표맵으로 mm 치수 →
  SVD 평면 피팅으로 픽포인트(중심+법선+기울기)
- **성과**: 박스 148개 검출, 상면 293.0±9.2 × 218.8±9.9mm(변동계수 3%), 기울기 평균 0.95°,
  층간 깊이차로 박스 높이 283mm 도출. 픽 순서(어느 박스가 언제 빠졌는지)까지 자동 복원
- **어필 포인트**: "사람이 교시하지 않아도 비전이 파지점을 만들어낸다" = 무교시 기술의 본질.
  딥러닝 이전에 센서 물리를 이해하고 베이스라인을 세운 뒤 학습 모델과 비교하는 접근

### ② 센서 노이즈 실측 모델링 (JD: "합성 데이터", sim2real의 근거)

- **행동**: 30세션에서 정적 픽셀 12.7만 개를 자동 선별해 깊이 반복 측정치의 산포 분석
- **성과**: **σ(mm) = 180.3 × I^(-0.805)** — 이 센서는 거리가 아니라 수신 강도가 노이즈를 지배
  (거리 기반 표준 모델이 부적합함을 데이터로 증명). 픽포인트 평면 RMS 5.4mm와 교차 검증 일치
- **어필 포인트**: 남들이 기본값으로 쓰는 노이즈 모델을 실측으로 반박하고 대체 — "측정 없이는 모델 없다"

### ③ 강화학습 환경 구축 + 학습 (JD: "물리엔진 시뮬레이션 활용 강화학습 환경 구축")

- **행동**: 실측 치수·산포로 시드한 팔레타이징 heightmap 환경을 직접 설계(관측·보상·지지율 제약·
  action mask). **초기 보상 설계 결함(고정 박스 수 → 상수 보상)을 학습 곡선에서 발견하고 재설계**
- **성과**: MaskablePPO 1.5M 스텝 → 동일 시드 100 에피소드 공정 평가에서 **64.9박스/활용률 68.5%±0.6**
  vs DBL 휴리스틱 56.6박스/59.8% — **+14.7% 박스, +8.7%p 활용률, 분산 7배 감소**
- **어필 포인트**: 환경을 "만들 줄" 아는 것(보상 설계 실패→진단→재설계 스토리)이 RL 라이브러리
  사용 경험과의 차별점

### ④ 인식-정책 통합 · 검증 (JD: "로봇이 사물 인지/상황판단 → 로봇 제어와 연동")

- **행동**: 실장면 인식 결과를 RL 환경 상태로 이식(등척 그리드 매핑·층 스냅·구멍 채움) →
  학습된 PPO가 목적지 스택 위 배치(PLACE) 제안 · 최소 동선 픽(PICK NEXT) 제안 → 실제 이미지로 역투영
- **성과**: **실제 작업 픽 순서와 대조 검증 — 실제 픽의 거리순위 평균 1.69위, 그리디 예측 top-2 81%.**
  이적재 공정 전체(소스 감소↔목적지 스택 성장 770→1260mm)를 ToF만으로 복원
- **어필 포인트**: 데모가 아니라 **실제 로그로 검증된** 인식↔의사결정 연동. 도메인 지식 반영 과정
  (공정 오해→소유자 확인→재설계)까지 문서화

### ⑤ 로봇 학습 인프라 (JD: "로봇 Foundation 모델 응용", "모방학습")

- **행동**: LeRobot 0.6 파이프라인 구축(Windows 특유 이슈 6건 해결·문서화 — torch 2.9+ 리그레션,
  심링크 권한, extras 구조 등), Diffusion Policy 263M 학습, **SmolVLA-450M 파인튜닝**
- **성과**: SmolVLA 20k 스텝 파인튜닝 loss 0.64→0.13, 2시간6분, **VRAM 피크 4.7GB/10GB 실측**
  (π0/GR00T급이 24-40GB로 불가함을 근거로 모델 선정 — 자원 제약 하 의사결정)
- **어필 포인트**: "VLA를 써봤다"가 아니라 "어떤 VLA가 어떤 자원에서 왜 되는지/안 되는지 실측했다"

### ⑥ 합성데이터 → sim2real (진행 중, JD: "합성 데이터 생성")

- **행동**: 실측 지오메트리(카메라 초점거리·높이·박스 치수)를 역산해 BlenderProc 물리 시뮬 씬 구축
  (합성 상면 깊이 2982 vs 실측 2973mm — 9mm 정합), 실측 노이즈 법칙 주입 ablation 설계
- **목표 성과**: 합성 전용 학습 검출기의 실데이터 mAP — clean vs 실측노이즈 주입 비교로 갭 정량화

## 3. 면접 예상 질문 & 답변 포인트

| 질문 | 답변 뼈대 |
|---|---|
| 왜 딥러닝 안 쓰고 기하로 시작했나 | 센서 물리 이해 + 베이스라인 확보 후 학습 모델의 기여를 정량 비교하기 위해. 결과적으로 무라벨로 148박스/3% 변동계수 달성 |
| RL 환경 설계에서 가장 어려웠던 것 | 보상 설계 결함(상수 보상) 발견·재설계 경험 — 학습 곡선이 안 오르는 원인을 환경에서 찾은 과정 |
| sim2real 갭을 어떻게 줄이나 | 일반론(DR) 이전에 **자기 센서의 노이즈 법칙 실측**(σ∝I^-0.8) — 거리 기반 기본 모델이 틀렸음을 확인한 사례로 답변 |
| 실로봇 경험은 | LeRobot 파이프라인·HIL-SERL 워크플로 구축 + (예정) 가상 SO-101 텔레옵→정책. 실기 확장 계획 제시 |
| 이 결과 믿을 수 있나 | 전 실험 동일시드 공정평가·실제 작업로그 대조검증·교차검증(노이즈 모델↔평면 RMS) 구조로 설계했음을 강조 |
